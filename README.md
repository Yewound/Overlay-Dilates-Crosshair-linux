# Overlay-Dilates-Crosshair-linux

A simple and lightweight screen crosshair overlay for Linux.

## Installation

You can easily clone this repository and install the application shortcut to your system menu using the terminal.

Open your terminal and run the following commands:

```bash
git clone https://github.com/Yewound/Overlay-Dilates-Crosshair-linux
cd Overlay-Dilates-Crosshair-linux
chmod +x install.sh
./install.sh
```

After running the script, you will find **Dilates Crosshair** in your system's application menu (under the "Games" or "Utilities" section).
